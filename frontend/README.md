# Crossway Drop — Frontend

Modern, high-performance web interface for ultra-fast cross-platform file and application sharing.

## Features
- **4× Parallel Streaming Engine**: Sends massive files (up to 500GB+) with multi-worker concurrent channels.
- **Universal Application Support**: Android APKs, macOS .app bundles, Windows EXE/MSI, and Linux packages.
- **Sleek UI**: Responsive design with light and dark mode support.
