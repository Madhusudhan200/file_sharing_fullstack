# Crossway Drop — Backend

High-speed Node.js / Express server for parallel streaming file and application sharing with zero-lock positional multi-channel disk writing.

## Features
- **Parallel Chunked Positional Writing**: Multi-gigabit throughput directly to disk.
- **500GB+ Support**: Memory-safe streaming without Node.js buffer limitations.
- **QR Code & Short Code Routing**: Secure 6-digit drop codes and auto-expiration after 24 hours.

## Setup & Run
```bash
npm install
npm start
```
